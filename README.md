# Sawfa Trip — Travel Agent Lombok

Website resmi **Sawfa Trip**, travel agent yang berbasis di Lombok, Nusa Tenggara Barat.

## Isi Website

- **Bilingual Indonesia / Inggris** — tombol ganti bahasa di header mengubah seluruh isi website
- **Paket Tour Lombok** — Rinjani, Snorkeling 3 Gili, Pink Beach, Mandalika & Pantai Selatan, Budaya Sasak Sade, Gili Trawangan
- **Halaman detail paket** — setiap paket memiliki halaman detail berisi penjelasan, itinerary, harga, dan rincian termasuk / tidak termasuk
- **Menu Transport** — layanan transportasi & antar-jemput di Lombok
- **Form Booking** — terhubung ke WhatsApp dengan ringkasan dan estimasi total otomatis
- Logo resmi Sawfa Trip (transparan) dengan palette brand: teal `#30B3B5`, navy `#03487F`, kuning `#FDC708`, oranye `#FC9B09`, hijau palem `#327846`

## Teknologi

Website statis dalam satu file `index.html` (semua gambar & aset sudah menyatu di dalamnya), siap di-deploy ke Vercel atau static hosting lainnya.

## Catatan

Harga paket yang tampil di website masih berupa **contoh estimasi** dan nomor WhatsApp masih placeholder — keduanya akan diganti dengan data resmi Sawfa Trip.
